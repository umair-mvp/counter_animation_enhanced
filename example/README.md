# counter_animation_enhanced example

A small app that shows `AnimatedCounter` from [counter_animation_enhanced](https://pub.dev/packages/counter_animation_enhanced).

Run it with:

```sh
flutter run
```

It counts a large number up from zero so the wheels are all turning at once, then
shows the same number in its other shapes: currency with a prefix, Indian
grouping, a percentage with decimals and a suffix, a negative temperature, a
zero-padded readout, and a counter held still by reduce motion. The slider at the
bottom drives the value by hand, so you can watch a single wheel turn.
